# English Kids

Бесплатный тренажёр правописания английских слов для 2–4 классов. Два локальных профиля, четыре режима
(«Напиши слово», «Вставь буквы», «Работа над ошибками», «Диктант»), озвучка английских слов, прогресс в браузере, работа без интернета
после первой загрузки, установка на телефон как приложение (PWA).

Без сервера, регистрации, рекламы, платных API и сбора личных данных.

## Что внутри

```
src/
  data/words.ts          словарь: 258 слов, 16 тем, 2–4 класс
  lib/check.ts           проверка ответов и пропущенных букв
  lib/progress.ts        прогресс, трудные слова, подбор слов для тренировки
  lib/storage.ts         сохранение в localStorage, экспорт/импорт JSON
  lib/speech.ts          озвучка слов (встроенный синтез речи браузера)
  lib/*.test.ts          тесты (41 проверка)
  screens/               экраны: выбор ребёнка, меню, тренировка, диктант, прогресс, родители
  components/            поле-пропись, общие элементы
public/
  icons/                 иконки 192×192, 512×512, maskable, apple-touch-icon
  _headers               заголовки кеширования для Cloudflare Pages
vite.config.ts           сборка + PWA (manifest, service worker, офлайн-кеш)
```

## Запуск на компьютере

Нужен Node.js 20 или новее (https://nodejs.org).

```bash
npm install        # один раз: установить зависимости
npm run dev        # открыть http://localhost:5173
```

Команда `npm run dev` с флагом `--host` также показывает адрес вида `http://192.168.x.x:5173` — его можно
открыть с телефона в той же Wi‑Fi сети, чтобы посмотреть интерфейс. Установка PWA и офлайн-режим работают
только после публикации по HTTPS (см. ниже).

## Проверка

```bash
npm run typecheck  # проверка TypeScript
npm test           # тесты: проверка слов, пропущенных букв, изоляции профилей, сохранения
npm run build      # production-сборка в папку dist/
npm run preview    # посмотреть собранную версию
npm run check      # всё сразу: typecheck + тесты + сборка
```

## Публикация на Cloudflare Pages (бесплатно)

Вариант 1, через GitHub (обновляется сам после каждого изменения):

1. Создайте репозиторий на GitHub и загрузите туда папку проекта (без `node_modules` и `dist`).
2. Откройте https://dash.cloudflare.com → **Workers & Pages** → **Create** → вкладка **Pages** →
   **Connect to Git** и выберите репозиторий.
3. Настройки сборки:
   - Framework preset: **Vite** (или None)
   - Build command: `npm run build`
   - Build output directory: `dist`
4. Нажмите **Save and Deploy**. Через 1–2 минуты появится адрес вида `https://english-kids.pages.dev`.

Вариант 2, без GitHub: соберите проект у себя (`npm run build`) и загрузите папку `dist` через
**Create → Pages → Upload assets**, либо командой `npx wrangler pages deploy dist`.

Версия Node задаётся файлом `.nvmrc` (20).

## Установка на телефоны

- **Android (Chrome):** откройте адрес сайта → меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- **iPhone / iPad (Safari):** откройте адрес сайта в Safari → кнопка «Поделиться» → «На экран „Домой“».

После первого открытия приложение работает без интернета. Каждое устройство хранит свой прогресс; на одном
телефоне могут заниматься оба ребёнка — у каждого свой профиль.

## Резервная копия

«Для родителей» (на главном экране) → решить пример → «Сохранить в файл». На другом устройстве:
«Загрузить из файла». Так же можно переименовать профили, выбрать значок и цвет, сбросить прогресс.

## Как устроено обучение

- Слово считается выученным после **трёх верных ответов подряд в разных тренировках**. Повтор в той же
  тренировке серию не увеличивает.
- Ошибка сбрасывает серию: слово становится «трудным», возвращается в конец текущей тренировки и занимает до
  половины мест в следующих.
- Проверка не учитывает регистр, лишние пробелы, точку в конце; дефис и пробел равнозначны (`ice-cream` =
  `ice cream`); можно писать с артиклем или `to` (`a cat`, `to swim`). Принимаются альтернативы из словаря
  (`grey`/`gray`, `mum`/`mother`). Для дней недели и месяцев ответ с маленькой буквы засчитывается, но с
  подсказкой про большую букву.
- Русская раскладка (в том числе одна русская буква в английском слове) и пустой ответ не считаются ошибкой —
  приложение просит переключить клавиатуру или написать слово.

## Озвучка

Слова произносит встроенный в браузер синтез речи (Web Speech API): бесплатно, без внешних сервисов и без
новых зависимостей. Выбирается британский голос, если он есть на устройстве, иначе американский.

- После каждого ответа правильное слово произносится автоматически. Отключить: «Для родителей» → «Озвучка».
- Кнопка с динамиком: в «Вставь буквы» (сразу), в «Напиши слово» (после проверки), в результатах, в диктанте
  (только в таблице после завершения) и в списке трудных слов.
- В «Напиши слово» и в диктанте звук до ответа не включается, чтобы не подсказывать.
- Офлайн работают голоса, установленные на устройстве. На iPhone они есть всегда. На Android, если звука нет:
  Настройки → «Синтез речи» (Text-to-speech) → движок Google → установить английский язык.
- На iPhone проверьте, что выключен беззвучный режим.

## Словарь

Темы ориентированы на уровень учебников «Enjoy English» (М. З. Биболетова), но словарь не является полной или
официальной копией учебника. Чтобы добавить слово, допишите строку в нужную тему в `src/data/words.ts`:

```ts
['кошка', 'cat', '🐱'],                 // русский, английский, картинка
['серый', 'grey', '', ['gray']],         // с допустимыми вариантами
```

ID создаётся автоматически. После правки запустите `npm test` — тесты проверят, что ID уникальны и написания
корректны.
